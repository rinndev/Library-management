# Library Management

## Deskripsi

Aplikasi Sistem Manajemen Perpustakaan menggunakan Express.js dan MySQL.

Library Management adalah aplikasi berbasis web yang digunakan untuk mengelola data perpustakaan secara mudah dan efisien. Aplikasi ini memiliki fitur CRUD Buku dan CRUD Peminjaman yang saling berelasi, sehingga pengguna dapat menambah, melihat, mengubah, dan menghapus data buku maupun transaksi peminjaman. Aplikasi dibangun menggunakan Express.js, MySQL, serta HTML, CSS, dan Bootstrap sebagai antarmuka pengguna.

## Fitur

- CRUD Buku
- CRUD Peminjaman
- Relasi Buku dan Peminjaman

## Install

```bash
npm install
```
